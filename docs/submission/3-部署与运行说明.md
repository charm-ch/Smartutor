# 「智学」部署与运行说明

> 本作品已在比赛服务器完整部署并通过验收（`curl /health` → 200，回归测试 4/4 全绿）。
> 本说明面向"从零复现部署"，约 30 分钟可完成。

## 1. 环境要求

| 组件 | 版本/说明 |
|---|---|
| OS | Linux（Ubuntu 22.04/24.04 均可） |
| Python | 3.12 |
| Node.js | ≥ 20（构建前端用） |
| PostgreSQL | ≥ 15 |
| 系统依赖 | `bubblewrap`（代码沙箱）、`gcc`（运行 C 代码沙箱）、libpq |
| 模型接入 | 中国科大 LLM 网关 API Key（OpenAI 兼容协议） |

## 2. 目录结构

```
smartutor/
├── backend/          # FastAPI 后端
│   ├── app/          # 应用代码（api/services/core/schemas）
│   ├── .env.example  # 环境变量样例
│   └── requirements.txt
├── frontend/         # Next.js 前端
├── tools/            # 运维与验收脚本（ci-check.sh / hash-manifest.py / accept2/ 评测脚本）
├── docs/             # 设计文档 / 进度文件 / 评测报告
└── Agent.md          # 开发规则（棘轮流程）
```

## 3. 后端部署

```bash
# 3.1 虚拟环境与依赖
cd smartutor/backend
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt          # 国内可用 -i https://pypi.mirrors.ustc.edu.cn/simple

# 3.2 环境变量
cp .env.example .env
# 编辑 .env：
#   DATABASE_URL=postgresql://<user>:<password>@localhost:5432/zhixue
#   API_TOKEN=<自定义访问令牌，留空则不启用鉴权>
#   KB_DATA_DIR=/opt/zhixue/data

# 3.3 数据库（应用启动时会自动幂等建表，仅需保证账号有建表权限）
sudo -u postgres psql -c "CREATE DATABASE zhixue;"
sudo -u postgres psql -c "CREATE USER zhixue WITH PASSWORD '...'; GRANT ALL ON DATABASE zhixue TO zhixue;"

# 3.4 模型配置 data/settings.json（首次启动自动生成，或手工放置）
{
  "api_base_url": "https://api.llm.ustc.edu.cn/v1",
  "api_key": "<你的网关 API Key>",
  "chat_model": "deepseek-v4-flash",
  "embedding_model": "BAAI/bge-small-zh-v1.5",
  "embedding_use_local": true
}

# 3.5 启动（开发验证）
uvicorn app.main:app --host 0.0.0.0 --port 8000
curl http://localhost:8000/health     # 期望 200
```

## 4. 前端部署

```bash
cd smartutor/frontend
npm install
# .env.local：NEXT_PUBLIC_API_BASE=http://<host>:8000  NEXT_PUBLIC_API_TOKEN=<与后端一致>
npm run build && npm start          # 默认 3000 端口
```

## 5. 生产托管（可选）

参考 systemd 单元（服务器现网使用同款）：

```ini
# /etc/systemd/system/zhixue-backend.service
[Service]
WorkingDirectory=/opt/zhixue/backend
ExecStart=/opt/zhixue/backend/.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
Environment=HF_ENDPOINT=https://hf-mirror.com
Environment=HF_HUB_OFFLINE=1
Restart=always
```

前端同理（`npm start`）。`systemctl enable --now zhixue-backend zhixue-frontend`。

## 7. 常见问题

- **首次启动卡在模型下载**：本地 embedding（bge-small-zh-v1.5）首次运行需从 HF 镜像下载，之后离线可用；离线环境请提前放置模型缓存并设 `HF_HUB_OFFLINE=1`。
- **PDF 解析失败**：纯扫描件走 OCR 路径，耗时较长属正常；确认系统已安装 OCR 依赖。
- **沙箱不可用**：确认 `bubblewrap` 已安装且当前用户有 bwrap 权限。
- **上传返回 413/415**：仅接受 ≤50MB 的 PDF，属预期防护行为。
