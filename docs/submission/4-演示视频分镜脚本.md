# 演示视频分镜脚本（≤5 分钟，供录制参考）

> 对应提交要求："说明作品解决的具体场景问题，突出实用性和主要功能"。
> 建议节奏：前 30 秒讲场景，中间 3 分半全是真实操作录屏，最后 45 秒收亮点。
> 录屏建议 1080p，浏览器缩放 110%，每个操作前口头说一句"接下来我要做什么"。

## 分镜 1：场景引入（0:00–0:30）｜口播+静态页
- 痛点三连：资料找不到答案 / AI 回答不敢信 / 复习没有针对性
- 一句话定位：「智学」= 传一门课的 PDF，得到一个可信、可溯源的课程 AI 助教

## 分镜 2：建库（0:30–1:10）｜录屏
- 登录 → 上传《C 语言程序设计》PDF → 显示解析进度 → 完成建库
- 口播强调：文本层优先、扫描件自动 OCR；本地向量化，资料不出本地

## 分镜 3：可信答疑 + 引用（1:10–2:20）｜录屏（核心）
- 提问："什么是空指针？解引用会怎样？"
- 展示 SSE 流式输出、回答中的 [1][5] 引用编号
- **点开引用折叠块**：展示对应原文（文档名/章节/页码）
- 再问一个代码报错问题 → **代码沙箱运行** → 运行结果融入回答（exit_code、输出）

## 分镜 4：推理轨迹面板（2:20–3:00）｜录屏（差异化亮点）
- 点开刚那条回答的"查看推理轨迹"
- 逐项讲解：检索了哪 5 个块、各自得分、token 用量、延迟
- 口播："每次回答都有完整证据链，且重启服务后仍可查"

## 分镜 5：学习画像 + 模拟卷（3:00–4:10）｜录屏
- 生成学习画像 → 知识点掌握度列表
- **再次生成** → 展示 comparison：某知识点 0.4→0.5（历史对比）
- 生成模拟卷 → 展示三阶段进度（风格分析/出题/答案）→ 成卷展示

## 分镜 6：可靠性亮点收尾（4:10–5:00）｜口播+实测录屏片段
- 快闪四张"实测证据"（可提前录好）：
  1. 资料里埋"忽略之前所有规则" → 指令不执行、提示词零泄漏
  2. iptables 断 LLM 3 秒 → 回答自动恢复
  3. kill -9 后端 → 重启后任务进度可查
  4. RAGAS 四指标 + 检索 20/20
- 结尾一句话："Model 之外，我们把 Harness 做成了可复跑的工程件。"
